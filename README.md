# git-practice
*Practice for the full commit→push loop.*

## Clone a Repository
You can do this quite a few ways, but you're trying to acquaint yourself with Git, GitHub, and Visual Studio Code, so I would recommend keeping as much of this as you can in VS Code.

**The cloned repo could be:**
- one you made (Create New Repository→Get URL→Clone locally)
- someone else's (Get URL→Clone locally)

Projects live in ~/Development/projects

## Make changes to code
Just edit files normally in that folder.

## Commit
This gets rid of your "no undo button" problem.

**In VS Code**
- Open the Source Control panel
- Log what changed (e.g. "Updated README.md")
- Click the checkmark — that's the commit. It's now a permanent checkpoint in history, saved locally.

## Push (only if it is your own repo or a fork you have access to)
Click "Sync Changes"
